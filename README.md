# GT-THEMES — موقع الدعم وشروح الثيمات

| | |
|---|---|
| **الموقع** | https://gehad450.github.io/gt-themes/ |
| **لوحة التحكم** | https://gehad450.github.io/gt-themes/admin/ |
| **المستودع على GitHub** | https://github.com/GEHAD450/gt-themes |
| **النسخة على الجهاز** | `D:\GT-THEMES\gt-themes-site` |

موقع ثابت (ملفات فقط) يُنشر على GitHub Pages. فيه: الخدمات، قسم لثيمات **سلة** وقسم لثيمات **زد**، ولكل ثيم صفحة شرح: صورة لكل قسم بأسهم مرقّمة، ما يفعله، وطريقة إعداده، ورابط المعاينة الحيّة، وقائمة «متاجر فعّلت الثيم». زر واتساب ومواعيد العمل في كل الصفحات.

## كيف أعدّل الموقع؟ (بدون أي برمجة)

افتحي لوحة التحكم من الرابط أعلاه — أو من «لوحة التحكم» أسفل أي صفحة — واكتبي كلمة المرور.

| التبويب | ماذا أفعل فيه |
|---|---|
| **الثيمات والشروح** | أضيف ثيماً جديداً، أرفع صورة الغلاف وصور الأقسام (سطح مكتب وجوال)، أكتب الشرح والخطوات والإعدادات تحت كل صورة، أضع **أسهماً مرقّمة** على الصورة (بالضغط على المكان) وأكتب شرح كل سهم، أضيف **أشكال الثيم / متاجره التجريبية** بصورها وروابط المعاينة، وأعدّل أو أحذف أو أرتّب أي قسم |
| **متاجر فعّلت الثيمات** | أضيف متجراً (اسمه، رابطه، الثيم) أو أعدّله أو أحذفه |
| **الصفحة الرئيسية وبياناتي** | رقم الهاتف وواتساب والبريد، **مواعيد العمل**، العنوان والنبذة، **الخدمات**، بطاقات «لماذا GT-THEMES»، الخبرة، الأرقام |
| **كلمة المرور** | أغيّر كلمة مرور اللوحة |

كل ضغطة «حفظ» تُسجَّل في GitHub، والموقع يعيد بناء نفسه ويُظهر التعديل خلال **دقيقتين تقريباً**.

### أول مرة فقط: تجهيز اللوحة

اللوحة تحتاج «مفتاحاً» من حسابك في GitHub لتستطيع الحفظ. تُدخلينه مرة واحدة وتختارين كلمة مرور، وبعدها الدخول بكلمة المرور فقط.

1. GitHub ← صورتك أعلى اليمين ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. **Repository access**: «Only select repositories» ثم اختاري `gt-themes`.
3. **Permissions** ← **Repository permissions** ← **Contents**: «Read and write».
4. **Expiration**: سنة. ثم **Generate token** وانسخي المفتاح.
5. افتحي لوحة التحكم، الصقي المفتاح واكتبي كلمة مرور قوية (١٠ أحرف على الأقل، لا تستخدمينها في مكان آخر).

**كيف تُحمى اللوحة؟** المفتاح يُحفظ في المستودع مشفّراً بكلمة مرورك (`content/admin.json`). بدون الكلمة هو نص غير مفهوم، ولا أحد غيرك يستطيع الحفظ.

- **نسيتِ كلمة المرور؟** من شاشة الدخول: «أعيدي الإعداد بمفتاح GitHub جديد».
- **انتهت مدة المفتاح بعد سنة؟** أنشئي مفتاحاً جديداً بنفس الخطوات وأعيدي الإعداد.
- **للإلغاء فوراً:** احذفي المفتاح من صفحة Personal access tokens في GitHub.

## أين المحتوى؟ (لمن يريد التعديل يدوياً)

| الملف | ما فيه |
|---|---|
| `content/profile.json` | الاسم، النبذة، الخدمات، المميزات، مواعيد العمل، الخبرة، البريد، الهاتف، واتساب |
| `content/stores.json` | المتاجر التي فعّلت الثيمات |
| `content/themes/<الثيم>.json` | شرح الثيم: المجموعات والأقسام (الشكل موصوف في `content/SCHEMA.md`) |
| `public/docs/<الثيم>/` | صور الثيم: الغلاف وصور الأقسام (WebP) |
| `public/brand/` | ملفات الشعار (PNG بخلفية داكنة / فاتحة / شفافة، وصورة مربعة للحسابات، وSVG) |
| `content/admin.json` | قفل اللوحة — لا يُعدَّل باليد |

تعديل أي ملف من موقع GitHub نفسه (زر القلم ✏️ ثم Commit) يحدّث الموقع بنفس الطريقة.

## التشغيل على الجهاز

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # يبني الموقع في مجلد out
```

اللوحة تحفظ من عنوان الموقع المنشور فقط (تحتاج إلى المستودع).

## النشر

الملف `.github/workflows/pages.yml` يبني الموقع وينشره مع كل تغيير على الفرع `main` — ومنها تعديلات لوحة التحكم.
مرة واحدة في المستودع: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
